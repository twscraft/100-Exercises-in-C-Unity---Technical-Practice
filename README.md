# 100 Exercises in C# & Unity

A personal technical practice project focused on strengthening my C# programming and Unity development skills through 100 progressively challenging exercises.

Each exercise is independently implemented, tested, documented, and organized inside a single Unity project.

---

## About the Project

This project is based on the book:

**100 ejercicios en C# para Unity: Cómo mejorar tu kungfú**

The goal is not only to complete the exercises, but also to document the learning process behind each implementation.

For every exercise, I document:

- The objective of the exercise
- My approach to solving the problem
- The implementation
- Screenshots of the result
- Technical challenges
- What I learned
- Relevant source code

## Technologies

- **C#**	Programming language
- **Unity**	Game engine and development environment
- **Git**	Version control
- **GitHub**	Source control and project documentation
- **LaTeX**	Technical reports
