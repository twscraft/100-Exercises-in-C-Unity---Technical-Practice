## About the Project

This project is based on the book:  
**100 ejercicios en C# para Unity: Cómo mejorar tu kungfú**

The goal is not only to complete the exercises, but also to document the learning process and engineering decisions behind each implementation.

For every exercise, I document:

- **Objective:** The core problem of the exercise.
- **Approach:** Logic and architecture designed to solve the problem.
- **Implementation:** Step-by-step integration within Unity.
- **Visual Results:** Screenshots or GIFs of the working exercise.
- **Technical Challenges:** Roadblocks encountered and how they were resolved.
- **Key Takeaways:** New concepts, patterns, or APIs learned.
- **Source Code:** Annotated C# scripts.
